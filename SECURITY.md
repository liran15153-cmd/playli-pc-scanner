# Security reports

Please use the [PLAYLI contact page](https://playli.co/pages/contact) to report
a suspected vulnerability privately. Include the affected source version and
a minimal reproduction without real hardware reports, transfer capabilities,
account credentials or customer data. Do not publish those values in an issue.

The scanner must remain a one-shot, unprivileged hardware reader with a fixed
HTTPS destination. A generic executable must exit before collection. Network
failures must remain bounded, redirects disabled, report fields allowlisted,
and no service, startup registration or personal-file access may be added.
